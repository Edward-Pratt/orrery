# packs

Packs, the Pack library and uploads (CONTEXT.md). `packs.ts` is a Minecraft server's pack: its state, Extras, config
edits, Kept paths and pack updates; `library.ts` the stored pack versions and Java runtimes; `uploads.ts` the chunked
uploads packs and save uploads share. Each file's header is its contract. Tests: `test/packs/`.
