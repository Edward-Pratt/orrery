# Licences

All four typefaces are under the SIL Open Font License 1.1, which allows bundling and self-hosting. Ship the matching licence file wherever the font files go.

Each face has a latin and a latin-extended file in `fonts/`. The latin files and the extended files for Familjen Grotesk and Source Serif 4 come from the personal site and slate; the extended files for Hanken Grotesk and JetBrains Mono are from the Fontsource packages (5.3.0), under the same licence.

- `familjen-grotesk-OFL.txt` — Familjen Grotesk
- `HankenGrotesk-OFL.txt` — Hanken Grotesk
- `source-serif-4-OFL.txt` — Source Serif 4
- `JetBrainsMono-OFL.txt` — JetBrains Mono
